## Beschrijving
<!-- In de Beschrijving staat hoe je project er uit ziet, hoe het werkt en wat je er mee kan. -->
Mijn website is de ''video'' pagina. Je vindt hier bovenaan de header met verschillende functies erin. Daaronder is een gekleurd vlak met de naam van de pagina erop. In de header is een hamburgermenu, dark-/lightmode en een zoekfunctie. Het hamburgermenu kan je in-en uitklappen, de dark-/lightmode kan je aanklikken en het scherm wordt donker/licht en de zoekfunctie zoekt binnen de gehele website.

## Kenmerken
<!-- Bij Kenmerken staat welke technieken zijn gebruikt en hoe. Wat is de HTML structuur? Wat zijn de belangrijkste dingen in CSS? Wat is er met Javascript gedaan en hoe? Misschien heb je een framwork of library gebruikt? -->
Er is een header met daarin een logo, button en een nav. Onder de nav zit een button die de dark-/lightmode bepaalt. Een H1 met de naam van de pagina met marges eromheen.
De content bevat een article met daarin een iframe met een H2-tekst en ondertekst: p.
Er volgt nog een H3 die je verwijst naar meer video's die volgen en wederom een article met daarin a-linkjes die je verwijzen naar vorige artikelen.
